# Quick Start Guide

## 🚀 Get Started in 3 Steps

### 1. Install Dependencies
```bash
npm install
```

### 2. Set Up Required Files

**Create poster.mind:**
- Visit: https://mind-ar.github.io/mind-ar-js-doc/tools/compile
- Upload `assets/poster.png` (or your own target image)
- Download the generated `.mind` file
- Save as `assets/poster.mind`

**Add a 3D Model:**
- Download a GLB model from [Sketchfab](https://sketchfab.com) or create one in Blender
- Save as `assets/model.glb`

### 3. Run the App
```bash
npm run dev
```

Open the URL shown in your terminal (usually `http://localhost:5173`) and point your camera at the target image!

## 📝 File Checklist

Before running, ensure you have:
- ✅ `assets/poster.png` - Your target image
- ✅ `assets/poster.mind` - Compiled MindAR target (generate from poster.png)
- ✅ `assets/model.glb` - Your 3D model

See `README.md` for detailed instructions.
